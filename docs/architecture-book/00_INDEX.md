## איך עובדים על זה

1. המשתמש מאפיין פרק עם ChatGPT ומייצר קובץ md.
2. הקובץ נשלח לקלוד (בצ'אט או כקובץ מצורף).
3. קלוד מוסיף את הקובץ לתיקייה זו בשם עקבי (`CH-XXX_שם_הפרק.md`), מעדכן את האינדקס הזה, ומבצע commit + push לענף `claude/help-needed-8t0nkf` בריפו.
4. בכל שלב ניתן לבקש הרכבת כל הפרקים שהושלמו לקובץ Word אחד מסודר.

**הערה חשובה:** ה-repo הוא מקור האמת. אם השיחה עם קלוד מתחילה מחדש (session חדש), כל המידע כאן זמין תמיד — אין תלות בזיכרון השיחה.
