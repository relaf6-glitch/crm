# בקרה כפולה והגהה

לפני סגירת עבודה מריצים שני מעברים אנושיים־בהיגיון ואת הסריקות הממוכנות.

## מעבר 1: מבקר פנים (עקביות ומבנה)

בודק את שלמות העבודה כמכלול:

- עקביות עובדתית בין פרקים (אין סתירות, אין מספרים מתנגשים).
- מבנה: כל פרק על השלד האחיד; חריגות מסומנות ומנומקות.
- מספור: כותרות, פרקים, מדרגות, תואמים לגוף (למשל כותרת שאומרת "שבע מדרגות"
  והגוף מונה שבע).
- טענות בלי מקור: כל טענה עובדתית מגובה או מסויגת.
- קישוריות: כל פרק נקשר לבא אחריו.

תעד ממצאים בדוח מבקר פנים והחל תיקונים.

## מעבר 2: מגיה לשוני

בודק את פני השטח הלשוני:

- שגיאות דפוס, אותיות כפולות/חסרות, מילים כפולות.
- מרכאות עקביות; ציטוטים תחומים כראוי.
- מקפים (לפי כלל הברזל).
- ניקוד רק בציטוטי פסוקים מכוונים.
- משפטים ארוכים מדי, לשיקול פיצול.

תעד ממצאים בדוח מגיה והחל תיקונים. גיוון לשוני מכוון (למשל "איננו"/"אינו") נשמר,
אין להאחיד אותו בכוח.

## הסריקות הממוכנות

הרץ על כל קובצי המקור (מרקדאון) לפני בניית הוורד הסופי. שלד סקריפט:

```python
import re, glob
files = sorted(glob.glob('<workdir>/**/*.md', recursive=True))

# 1. מקפים אסורים
for f in files:
    for i, line in enumerate(open(f, encoding='utf-8'), 1):
        if line.startswith('[^'):        # שורות מקור/הערה עלולות להכיל URL
            pass
        for ch in ['—', '–']:            # em/en dash בכל מקום
            if ch in line: print(f'{f}:{i} EMDASH')
        if ' - ' in line: print(f'{f}:{i} SPACED-HYPHEN')      # בדוק שאינו בתוך URL
        for m in re.finditer(r'[א-ת]־[א-ת]', line):            # מקף מחבר עברי
            print(f'{f}:{i} MAQAF {m.group(0)}')

# 2. שלמות הערות שוליים (לכל קובץ)
for f in files:
    t = open(f, encoding='utf-8').read()
    refs = set(re.findall(r'\[\^(\d+)\](?!:)', t))
    defs = re.findall(r'^\[\^(\d+)\]:', t, re.M)
    if refs - set(defs): print(f'{f}: refs בלי הגדרה', sorted(refs - set(defs)))
    if set(defs) - refs: print(f'{f}: הגדרות בלי הפניה', sorted(set(defs) - refs))
    dup = [d for d in set(defs) if defs.count(d) > 1]
    if dup: print(f'{f}: כפל הגדרה', dup)

# 3. אותיות לטיניות בתוך מילים עבריות
for f in files:
    for i, line in enumerate(open(f, encoding='utf-8'), 1):
        for m in re.finditer(r'[א-ת][A-Za-z]|[A-Za-z][א-ת]', line):
            print(f'{f}:{i} LATIN-LEAK {line[max(0,m.start()-15):m.end()+15].strip()}')

# 4. ניקוד מחוץ לציטוטים, ומילים כפולות, לפי הצורך
```

כל ממצא שאינו בתוך כותרת מצוטטת או URL חייב תיקון לפני ההפקה. הרץ שוב עד אפס
ממצאים אמיתיים.

## הערה על מקפים בשורות מקור

מקפים בתוך כותרות כתבות מצוטטות ובתוך כתובות אינטרנט הם לשון המקור ומותרים. סנן
אותם בשיקול דעת: ממצא בשורת `[^n]:` שמכיל `http` או מרכאות של כותרת הוא לרוב
לגיטימי.
