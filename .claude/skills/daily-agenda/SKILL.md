# רשימת עבודה יומית (daily-agenda)

סקיל זה מנהל שגרה יומית קבועה מתוך המיילים והיומן של המשתמש. שלושה מצבים:

1. **בוקר** — ריכוז: קריאת מיילים חדשים + אירועי היום, והפקת רשימת עבודה.
2. **ערב** — סגירה: מעבר על הרשימה עם המשתמש, מה נסגר ומה נשאר פתוח.
3. **גלגול** — כל מה שנשאר פתוח בערב עולה אוטומטית לראש רשימת הבוקר הבא.

**שפה:** כל התוצרים והשיחה בעברית, יישור לימין.

**אזור זמן:** `Asia/Jerusalem`. כל שעה/תאריך מחושבים לפי אזור זה.

**ברירות מחדל** (ניתנות לשינוי בקובץ `state/config.md`):
- מיילים שנחשבים "משימה": לא-נקראים בתיבה הראשית מ-24 השעות האחרונות.
- ימי הפעלה: ראשון–חמישי.
- שעות: בוקר 07:00, ערב 21:00.

---

## קובץ המצב

מצב הסקיל נשמר תחת `state/`:

- `state/current.md` — הרשימה החיה של היום (עם תיבות סימון).
- `state/config.md` — העדפות המשתמש (מיילים שנחשבים, שעות, ימים).
- `state/log/YYYY-MM-DD.md` — ארכיון של רשימת כל יום שנסגר.
- `state/activity-log.xlsx` — קובץ אקסל מצטבר: פעילות לפי יום ומה נעשה.

**מוסכמות סימון בקובץ `current.md`:**
- `- [ ]` — לא בוצע (פתוחה, מתגלגלת למחר).
- `- [x]` — בוצע (נסגרה).
- `- [/]` — בוצע חלקית (מה שנשאר מתגלגל למחר, עם הערה).
- `- [~]` — נדחתה / לא רלוונטית (לא מתגלגלת הלאה).

הערות "מה נשאר" נכתבות בסוגריים בסוף השורה, למשל:
`- [/] מאת ספק — הצעת מחיר (נשאר: לאשר תקציב מול הנהלה)`

תמיד קרא את `state/config.md` בתחילת כל ריצה כדי לכבד העדפות עדכניות.

## מצב בוקר (morning routine)

כשמתבקש "סבב בוקר" / "רשימת עבודה" / טריגר "morning":

1. **קבע תאריך.** מצא את תאריך היום ואת שם היום בעברית (לפי `Asia/Jerusalem`).

2. **גלגל את הפתוח מאתמול.** קרא את `state/current.md` הקיים (אם יש):
   - אסוף כל שורה עם `- [ ]` (פתוחה) — אלה מתגלגלות.
   - העבר את הקובץ הישן לארכיון: `state/log/<תאריך-הקודם>.md`.
   - אם `current.md` כבר מהיום, אל תגלגל שוב — רק רענן אירועים/מיילים חדשים.

3. **קרא מיילים חדשים.** השתמש ב-`mcp__Gmail__search_threads` עם השאילתה
   מ-`config.md` (ברירת מחדל: `in:inbox is:unread newer_than:1d`). לכל תוצאה
   רשום פריט קצר: `מאת <שולח> — <נושא>`. אם יש הרבה, קבץ והבלט את החשובים.
   אל תיכנס לגוף כל מייל אלא אם הנושא לא ברור או המשתמש ביקש עומק.

4. **קרא אירועי היום.** השתמש ב-`mcp__Google_Calendar__list_events` על היומן
   הראשי, מתחילת היום ועד סופו (`Asia/Jerusalem`). כלול גם אירועי חגים אם
   רלוונטי. לכל אירוע: `<שעה> — <כותרת> (<מיקום/משתתפים אם יש>)`.

5. **הרכב את `state/current.md`** במבנה הזה:

   ```
   # רשימת עבודה — <תאריך> (<יום בעברית>)

   ## פתוח מאתמול
   - [ ] <משימות שהתגלגלו>

   ## אירועי היום (יומן)
   - [ ] <שעה> — <אירוע>

   ## מיילים לטיפול
   - [ ] מאת <שולח> — <נושא>

   ## הערות
   <ריק, למילוי במהלך היום>
   ```

   אם אין פריטים בקטגוריה — כתוב "אין" במקום להשאיר ריק.

6. **מסור למשתמש.** הצג את הרשימה בצ'אט בעברית מסודרת. אם רץ מטריגר מתוזמן
   (המשתמש כנראה לא נוכח), שלח גם `PushNotification` קצרה עם מספר הפריטים
   הפתוחים ושורת הכותרת, ואם המשתמש ביקש ערוצים נוספים ב-`config.md` (מייל /
   Artifact) — הפק גם אותם.

## מצב ערב (evening routine)

כשמתבקש "סבב ערב" / "מה נשאר פתוח" / טריגר "evening":

1. קרא את `state/current.md`.

2. **עבור פריט-פריט בצ'אט.** הצג את הפריטים הפתוחים ממוספרים, וקדם אותם
   אחד-אחד (או בקבוצה אם המשתמש מעדיף). לכל פריט שאל בעברית:
   "בוצע / לא בוצע / בוצע חלקית?" — ואם "חלקית", שאל "מה נשאר?".
   קבל תשובות גם בקיצור (מספר + סטטוס), ואל תמהר לפריט הבא בלי תשובה.

3. **הצלבה אוטומטית (עזר):** לפני השאלה, בדוק אם יש רמז לסגירה —
   למשל מייל שנקרא/נענה, או אירוע שעבר. הצע סימון והמתן לאישור. אל תסמן
   `- [x]` בלי אישור המשתמש.

4. עדכן ב-`current.md` לפי התשובות:
   - "בוצע" → `- [x]`.
   - "לא בוצע" → נשאר `- [ ]` (יתגלגל למחר).
   - "בוצע חלקית" → `- [/]` עם הערה `(נשאר: ...)` (החלק שנשאר מתגלגל).
   - "לא רלוונטי / בטל" → `- [~]` (לא מתגלגל).
   הוסף פריטים חדשים אם המשתמש מזכיר.

5. **כתוב לאקסל המצטבר.** הוסף את פעילות היום ל-`state/activity-log.xlsx`
   (ראה סעיף "אקסל פעילות" למטה) — שורה לכל פריט.

6. סכם: "בוצעו X, חלקית Y, נשארו פתוחות Z — יתגלגלו למחר." שמור את הקובץ,
   וקומיט את `current.md`, הארכיון והאקסל.

## אקסל פעילות (`state/activity-log.xlsx`)

קובץ מצטבר עם היסטוריית הפעילות. נכתב בסוף כל סבב ערב (או ידנית לבקשת המשתמש).

**מבנה גיליון אחד בשם `פעילות`, RTL, עם העמודות:**

| תאריך | יום | קטגוריה | פריט | סטטוס | מה נשאר / הערות |
|-------|-----|---------|------|-------|-----------------|

- **קטגוריה:** יומן / מייל / משימה.
- **סטטוס:** בוצע / לא בוצע / בוצע חלקית / בוטל.
- שורה אחת לכל פריט מ-`current.md` של אותו יום.

**כתיבה (append, לא דריסה):** השתמש ב-openpyxl (אם חסר: `pip install openpyxl`,
או הפעל את סקיל `xlsx`). אם הקובץ לא קיים — צור אותו עם
כותרות; אחרת פתח והוסף שורות בהמשך. הגדר `ws.sheet_view.rightToLeft = True`
ליישור עברית. דוגמה:

```python
import os
from openpyxl import Workbook, load_workbook

path = ".claude/skills/daily-agenda/state/activity-log.xlsx"
headers = ["תאריך", "יום", "קטגוריה", "פריט", "סטטוס", "מה נשאר / הערות"]
if os.path.exists(path):
    wb = load_workbook(path); ws = wb["פעילות"]
else:
    wb = Workbook(); ws = wb.active; ws.title = "פעילות"
    ws.append(headers); ws.sheet_view.rightToLeft = True
for row in rows:            # rows = רשימת רשומות היום
    ws.append(row)
wb.save(path)
```

אחרי הכתיבה, ציין למשתמש שהאקסל עודכן, וקומיט אותו.

## מודל ההפעלה: ידני + תזכורות

הסקיל רץ **ידנית בסשן חי** (דרך ב'), כי רק בסשן חי יש גישה מלאה ל-Gmail
וליומן. שתי **תזכורות** מתוזמנות (Routines) דוחפות למשתמש התראה לנייד:
- בוקר 07:00 (ראשון–חמישי): "תגיד לי 'סבב בוקר'".
- ערב 21:00 (ראשון–חמישי): "תגיד לי 'סבב ערב'".

התזכורות עצמן לא ניגשות למייל/יומן — הן רק מזכירות. כשהמשתמש נותן את הפקודה
בצ'אט, הסקיל מריץ את המצב המתאים עם גישה מלאה.

**הערת אזור זמן:** התזכורות מתוזמנות ב-UTC. בקיץ (IDT, +3) 07:00=04:00Z,
21:00=18:00Z. במעבר לשעון חורף (IST, +2, בסוף אוקטובר) הן יוקדמו בשעה —
אז יש לעדכן את ה-cron ל-`0 5` ו-`0 19`.

## שימור נתונים וגיזום

- **מקור אמת קבוע:** `state/activity-log.xlsx` בריפו. כל שורה מתועדת בו לתמיד,
  מגורסת ב-git. זהו הארכיון שאסור לאבד.
- **נתונים זמניים:** `state/current.md` (מתגלגל) ו-`state/log/*.md` (ארכיון יומי
  בטקסט). **מותר לגזום/למחוק** קבצי `log/*.md` ישנים בלב שקט — כל המידע כבר
  שמור באקסל. אל תמחק את האקסל.
- **עותק ל-Drive (אופציונלי):** לבקשת המשתמש אפשר להעלות עותק טרי של האקסל
  ל-Google Drive לצפייה נוחה מהנייד (דרך `create_file`). זהו עותק בלבד; מקור
  האמת נשאר בריפו. כלי ה-Drive לא תומכים בעדכון-במקום, לכן לא מנהלים שם מצב חי.

## כשמפעילים ידנית

המשתמש יכול לומר בכל רגע `/daily-agenda` או "תן לי את הרשימה". במקרה כזה זהה
לפי ההקשר אם הכוונה לבוקר (הפקה/רענון) או לערב (סגירה); אם לא ברור — שאל.
