# daily-agenda — רשימת עבודה יומית

סקיל שמנהל שגרה יומית מהמיילים והיומן:
- **בוקר** — מפיק רשימת עבודה ממיילים חדשים + אירועי היום.
- **ערב** — עובר על הרשימה, מסמן מה נסגר ומה נשאר פתוח.
- **גלגול** — הפתוח מהערב עולה לראש רשימת הבוקר הבא.

## שימוש ידני
בסשן פעיל, אמור אחד מאלה:
- `רשימת עבודה` / `סבב בוקר` — הפקה/רענון.
- `מה נשאר פתוח` / `סבב ערב` — סגירה.

## הפעלה אוטומטית (טריגרים יומיים)
כדי שהסקיל ירוץ לבד בבוקר ובערב צריך שני Routines (טריגרים מתוזמנים) שיפתחו
סשן טרי וישלחו את ההודעה המתאימה. יוצרים אותם פעם אחת:

- **בוקר** — ראשון–חמישי בסביבות 08:00, פרומפט:
  `הפעל את סקיל daily-agenda — morning routine`
- **ערב** — ראשון–חמישי בסביבות 20:00, פרומפט:
  `הפעל את סקיל daily-agenda — evening routine`

הערה: טריגר לסשן טרי משתמש בברירת המחדל של הריפו, לכן הסקיל צריך להיות מוזג
לענף הראשי כדי שהריצות האוטומטיות יראו אותו. עד המיזוג אפשר להריץ ידנית.

## קבצים
- `SKILL.md` — הלוגיקה של שלושת המצבים.
- `state/config.md` — העדפות (שעות, ימים, אילו מיילים נחשבים, ערוצי מסירה).
- `state/current.md` — הרשימה החיה.
- `state/log/` — ארכיון יומי.
