# daily-agenda — רשימת עבודה יומית

סקיל שמנהל שגרה יומית מהמיילים והיומן:
- **בוקר** — מפיק רשימת עבודה ממיילים חדשים + אירועי היום.
- **ערב** — עובר על הרשימה, מסמן מה נסגר ומה נשאר פתוח.
- **גלגול** — הפתוח מהערב עולה לראש רשימת הבוקר הבא.

## שימוש ידני
בסשן פעיל, אמור אחד מאלה:
- `רשימת עבודה` / `סבב בוקר` — הפקה/רענון.
- `מה נשאר פתוח` / `סבב ערב` — סגירה.

## מודל ההפעלה: ידני + תזכורות
הסקיל רץ ידנית בסשן חי (רק שם יש גישה מלאה למייל וליומן). שתי תזכורות
מתוזמנות דוחפות התראה לנייד להזכיר לך לתת את הפקודה:

- **תזכורת בוקר** — ראשון–חמישי 07:00 שעון ישראל → "תגיד 'סבב בוקר'".
- **תזכורת ערב** — ראשון–חמישי 21:00 שעון ישראל → "תגיד 'סבב ערב'".

התזכורות לא ניגשות למייל/יומן — רק מזכירות. הריצה עצמה מתבצעת כשאתה נותן
את הפקודה בצ'אט.

מדוע לא אוטומציה מלאה: טריגר שנוצר דרך ה-MCP פותח סשן טרי בלי חיבורי
Gmail/יומן, ולכן לא יכול לקרוא מייל או אירועים. אוטומציה מלאה אפשרית רק אם
יוצרים את ה-Routine מממשק claude.ai ומצרפים שם את החיבורים.

## שימור וגיזום
- `state/activity-log.xlsx` — הארכיון הקבוע (מקור אמת). לא מוחקים.
- `state/log/*.md` — ארכיון טקסט זמני; מותר לגזום ישנים, הכול שמור באקסל.

## קבצים
- `SKILL.md` — הלוגיקה של שלושת המצבים.
- `state/config.md` — העדפות (שעות, ימים, אילו מיילים נחשבים, ערוצי מסירה).
- `state/current.md` — הרשימה החיה.
- `state/log/` — ארכיון יומי.
- `state/activity-log.xlsx` — אקסל מצטבר: פעילות לפי יום ומה נעשה (נכתב בסבב הערב).
